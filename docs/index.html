Comment lire le score

Couverture : part des compétences demandées par l'offre que je possède. Score : somme de mes niveaux (sur 5) pour ces compétences, divisée par le nombre de compétences demandées + 2. Le « + 2 » évite qu'une offre dont une seule compétence a été extraite obtienne un score parfait : plus l'offre donne d'information, plus le score est fiable. Une offre non évaluable est une offre dont aucune compétence n'a pu être extraite (description Adzuna trop courte). Son score de 0 ne veut pas dire « mauvais match ».

Mes critères

Ils entrent dans le calcul du score. Une offre qui remplit un critère prioritaire voit son score augmenter. Une offre exclue sort du classement, du compteur et des graphiques. Les critères sont gardés dans ce navigateur.

Comment lire le score

Couverture : part des compétences demandées par l'offre que je possède. Score compétences : somme de mes niveaux (sur 5) pour ces compétences, divisée par le nombre de compétences demandées + 2. Le « + 2 » évite qu'une offre dont une seule compétence a été extraite obtienne un score parfait : plus l'offre donne d'information, plus le score est fiable.

Score ajusté (colonne « Score ») = score compétences × (1 + bonus × nombre de critères prioritaires remplis). Avec un bonus de 50 %, une offre dans un lieu prioritaire et d'un type prioritaire a son score multiplié par 2 ; une offre qui n'en remplit qu'un, par 1,5. Le multiplicateur est affiché sous le score. Les critères ne remplacent pas les compétences : une offre à 0 reste à 0, mais passe devant les autres offres à 0.

Une offre non évaluable est une offre dont aucune compétence n'a pu être extraite (description Adzuna trop courte). Son score de 0 ne veut pas dire « mauvais match ».
